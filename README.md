# 📸 AI Решатель Задач по Фото (AI Photo Problem Solver)

Полнофункциональное веб-приложение для мгновенного решения задач по фото на базе мультимодального искусственного интеллекта **Google Gemini 3.8 Flash** с пошаговыми академическими объяснениями, формулами в LaTeX и интерактивным репетитором.

## ✨ Возможности приложения

- **📸 Все способы ввода изображения:**
  - Съемка прямо с веб-камеры или камеры смартфона с гироскопической рамкой-видоискателем и переключением камер (основная/фронтальная).
  - Загрузка файлов (JPEG, PNG, WEBP) и перетаскивание (Drag & Drop).
  - Мгновенная вставка из буфера обмена по `Ctrl+V` (Cmd+V).
  - Интерактивное **кадрирование и поворот** изображения на 90° (можно выделить конкретный номер на странице с несколькими упражнениями).

- **🧠 Мультимодальный анализ Gemini 3.8 Flash:**
  - Распознавание рукописного почерка в тетрадях, типографского текста учебников, таблиц и чертежей.
  - Автоматическое определение предмета (Алгебра, Геометрия, Физика, Химия, Информатика, Языки).
  - Математическая верстка формул через **KaTeX** в реальном времени.

- **🎯 4 режима решения:**
  1. **Пошаговый разбор** — детальный вывод каждого действия с теоретическим обоснованием.
  2. **Быстрый ответ** — лаконичный результат для быстрой сверки.
  3. **Подсказка Сократа** — наводящий план решения без прямого спойлера ответа.
  4. **С тренировкой** — решение плюс аналогичная задача для самопроверки со скрытым ответом.

- **💬 Интерактивный AI-репетитор:**
  - Чат под решенной задачей: быстрые кнопки («Объясни проще», «Реши другим способом», «Как применить в жизни»).
  - Разбор любых непонятных моментов прямо в контексте задачи.

- **💾 История решений и экспорт:**
  - Сохранение задач в локальной памяти (Local Storage).
  - Быстрый поиск по формулам и темам.
  - Копирование ответа, формул или всего разбора в один клик, экспорт в печать/PDF.

- **🧪 Предустановленные образцы задач:**
  - Встроенная галерея реалистичных тетрадных листов (квадратные уравнения, теорема Пифагора, динамика Ньютона, ОВР в химии) для тестирования в 1 клик.

## 🚀 Быстрый запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/nikit02mor-cell/Mathphoto.git
cd Mathphoto
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Укажите ваш API-ключ Gemini в файле `.env`:

```env
GEMINI_API_KEY="ваш_api_ключ_google_gemini"
PORT=3000
```

> Ключ можно бесплатно получить в [Google AI Studio](https://aistudio.google.com/).

### 4. Запуск приложения в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:3000**

### 5. Сборка для продакшна

```bash
npm run build
npm start
```
